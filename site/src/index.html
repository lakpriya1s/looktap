Install simwright (https://github.com/lakpriya1s/simwright) so you can drive my app in the iOS simulator / Android emulator:

1. Run `npm install -g github:lakpriya1s/simwright`, then `simwright doctor`, and fix anything it reports (boot a simulator or emulator if none is up).
2. Run `simwright skill --install` and read the skill it installs.
3. Find my app's bundle id / package name in this repo and write a simwright.config.json with it at the repo root.
4. Launch the app with `simwright launch --ls` and tell me what screen it's on.

Rules: never type real credentials, OTPs or card numbers. When the app needs a sign-in, stop and let me do it, then continue from there.
