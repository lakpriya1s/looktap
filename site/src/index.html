Install looktap (https://github.com/lakpriya1s/looktap) so you can drive my app on an iPhone or Android device:

1. Run `npm install -g looktap`, then `looktap doctor`, and fix anything it reports (boot a simulator or emulator, or connect a device, if none is up).
2. Run `looktap skill --install` and read the skill it installs.
3. Find my app's bundle id / package name in this repo and write a looktap.config.json with it at the repo root.
4. Launch the app with `looktap launch --ls` and tell me what screen it's on.

Rules: never type real credentials, OTPs or card numbers. When the app needs a sign-in, stop and let me do it, then continue from there.
